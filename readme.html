🎨 Tailwind CSS Guide

How Tailwind CSS Works

🚀 Utility-First Approach

Instead of writing custom CSS, you use pre-built utility classes. For example:

<div class="bg-blue-500 text-white p-4 rounded-lg">
  This has blue background, white text, padding, and rounded corners
</div>

📝 Common Utility Patterns

Spacing & Layout
p-4 = padding 1rem
m-4 = margin 1rem
mx-auto = horizontal margin auto (center)
space-y-4 = vertical space between children
Typography
text-2xl = font size
font-serif = Playfair Display
font-sans = Inter
font-bold = font weight
text-center = text alignment
Responsive Design
md:grid-cols-3 = 3 columns on medium screens and up
lg:text-4xl = larger text on large screens
sm:p-8 = more padding on small screens

📋 Quick Reference

Layout
  • flex - flexbox container
  • grid - grid container
  • hidden - display: none
  • block - display: block
Sizing
  • w-full - width: 100%
  • h-screen - height: 100vh
  • min-h-screen - min-height: 100vh
  • max-w-4xl - max-width: 56rem

💡 Pro Tips

  • • Use container mx-auto px-4 for centered content containers
  • • Add transition duration-200 for smooth hover effects
  • • Use rounded-lg for consistent border-radius
  • • Prefix with screen sizes (sm:, md:, lg:) for responsive design
  • • Check the Tailwind Docs for complete reference
